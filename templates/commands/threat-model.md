description: "Create a lightweight STRIDE threat model for a change"
---

Build a lightweight STRIDE threat model for the requested scope.

## Process

1. Define the feature, trust boundaries, data flows, and external dependencies.
2. Enumerate STRIDE threats relevant to the scope.
3. Map each relevant threat to a concrete control or follow-up action.
4. Highlight items that require `agent-security-policies` skills or human review.
5. Return a concise markdown report with severity and recommended mitigations.
