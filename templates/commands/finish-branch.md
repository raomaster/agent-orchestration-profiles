---
description: "Safely close a development branch or worktree"
---

Finish a development branch after implementation and verification are complete.

## Process

1. Confirm the current validation status.
2. Identify the base branch.
3. Offer safe next actions: merge locally, push and open a PR, keep the branch, or discard it.
4. Require explicit confirmation for destructive cleanup.
5. Clean up the branch or worktree only when the chosen path makes it safe.
