description: "Turn a request into a decision-complete execution plan"
---

Create a decision-complete plan before implementation.

## Process

1. Clarify the objective, scope, and acceptance criteria.
2. Ask `Valkyrie-Scan` for read-only discovery when the codebase is unclear.
3. Break the work into independent tasks with explicit ownership.
4. Call out checkpoints, worktree usage, and security review needs.
5. Produce an ordered plan that leaves no unresolved implementation decisions on the critical path.
